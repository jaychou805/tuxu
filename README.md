# tuxu — 图需 Skill

跨境电商（亚马逊/TikTok Shop 等）产品做图/作图需求文档的填写与文案优化 Skill。

## 功能

填写并优化三类需求文档的文案：
- **主图做图需求文档**（1600×1600）：主标题/副标题/其他文案 + 卖点说明
- **A+ 作图需求文档**（1464×600）：产品图/细节/尺寸参数/场景/安装
- **视频需求文档**：分镜画面内容、英文字幕、需求细则

## 核心能力

- 从产品信息提炼**差异化卖点**（数字 > 形容词）
- 中文单位统一换算**美区英制单位**（cm→in、kg→lb）
- 按参考图版式写「布局/标题位置/色调」设计说明
- `.xls`/`.xlsx` 用 **WPS COM** 回写，完整保留嵌入图片

## 目录结构

```
tuxu/
├── SKILL.md               # 核心流程 + 关键规则
├── references/
│   ├── 文案规范.md         # 三类表格栏位写法 + 差异化提炼 + 常见错误
│   └── 写回技术方案.md     # .xls/.xlsx 保留图片的 WPS COM 方案
└── scripts/
    └── fill_xls.py        # 可复用回写脚本模板
```

## 使用

在 WorkBuddy 中，将本目录放入 `~/.workbuddy/skills/tuxu/`，然后说「用图需 skill 帮我填」并提供产品信息 + 图需表格即可。

## 关键规则

1. **首图**（图名含「首图」）B列只保留尺寸，不写标题/文案
2. **单位统一美区制**：cm→in、kg→lb，不保留公制
3. **对比图**不出现竞品品牌/商标
4. 视频满足：英文字幕 + 提卖点 + 真人出镜
