# 图需文案规范

跨境电商（亚马逊）做图需求文档的文案写法，用于主图、A+、视频分镜三类表格。

## 一、差异化提炼（先做这个）

拿到产品信息后，先与同行/竞品对比，找出**数字可量化的差异化优势**，这是文案的灵魂。

| 维度 | 示例：猪食投喂器 |
|---|---|
| 容量 | 9 蒲式耳 vs 同行 6-8 |
| 喂养量 | 20 头 vs 同行 6 头 |
| 结构 | 双向顶门 vs 单开门 |
| 安全 | 圆角卷边 vs 无 |
| 安装 | 预装螺母免安装 vs 需组装 |
| 适用 | 室内外耐候 vs 仅室内 |

**原则**：数字 > 形容词。「Feeds up to 20 Hogs」比「Large Capacity」更有力。

## 二、三类表格的栏位写法

### 1. 主图做图需求文档（1600×1600）

每张图两个核心栏位：

**「具体文案说明」列**（英文，模板格式 `尺寸（1600x1600）\n\n主标题文案：...\n副标题文案：...\n其他文案：...`）：
- **主标题**：短句卖点，3-6 词。例：`9-Bushel Pig Feeder — Feeds Up to 20 Hogs`
- **副标题**：补充说明或罗列要点。例：`Large Capacity | 2-Way Top Door | Heavy-Duty Metal`
- **其他文案**：编号卖点或参数。例：`1. Anti-Deformation Body\n2. Rounded Safety Edges`
- 无内容的栏位填 `（无）`。

**「产品详细卖点说明或要求」列**（中文，给美工看，按各行参考图版式写）：
- 布局：左图右文 / 上下结构 / 左产品右特写 / 场景拼接等
- 标题位置：顶部通栏 / 左上 / 居中
- 对应文案：呼应「具体文案说明」列
- 色调：延续全系列（如绿+橙农场风）
- 注意事项：单位、竞品商标、平台文字合规

**首图特殊规则**（图名含「首图」的行，如 图1-首图/图2-首图/图3-首图/图4-首图）：
- 「具体文案说明」列（B列）**只保留 `尺寸（1600x1600）` 一行**，不写主标题/副标题/其他文案三行。
- 「卖点说明」列（C列）只描述图片构成（白底、产品居中占比、展示角度、露出的结构），不写标题位置与文案。
- 其余图（尺寸图/卖点图/场景图/对比图）正常填标题、副标题、其他文案。

### 2. A+ 作图需求文档（1464×600 & 600×450）

- 图1 产品图：左图右文，主标题+4个卖点
- 图2 细节展示：左完整产品 + 右局部圆形特写
- 图3 尺寸参数：尺寸标注图 + 参数列表（含公制换算 mm、容量、材质、包材内容）
- 图4+ 细节/场景/安装：按各自主题写

尺寸参数模板（示例）：
```
External Size: 25.6" L x 32.68" W x 39.4" H (650 x 830 x 1000 mm)
Capacity: 9 Bushels (34.4 Gal / approx. 130 L)
Material: Galvanized Steel, Rust-Resistant
Feeds Up to 20 Hogs
Package Content: 1 x Pig Feeder, 1 x Instruction Manual
```

### 3. 视频需求文档

分镜三栏：画面内容、字幕（英文）、需求细则。

- **画面内容**（中文，详细）：景别 + 主体动作 + 画面元素层次（前/中/背景）+ 镜头运动 + 光线色调
- **需求细则**（中文，给拍摄）：运镜方式、动作要求、重点画面、光线、构图、剪辑节奏
- **叙事线**：可用「乱→序」对比结构（先展示痛点，再产品解决）

细则写法模板：
```
[运镜方式]，[主体动作要求]，重点突出[核心卖点]；光线[说明]；构图[说明]；[其他注意]
```

## 三、常见错误规避

1. **残留文案**：模板表会残留上一单产品内容，务必全查全换。
2. **单位统一美区制**：尺寸/重量/容量一律换算美区英制——cm→in（英寸，26.18"）、kg→lb（44.1 lbs）、L→gal 等，**不保留公制单位**（cm/kg/L），除非用户明确要求。修正 "20m"→"20in" 类拼写错误。
3. **直译腔**：避免 "No Deformation""Optimal Yield" 这类生硬表达，用母语化 "Built to Last"。
4. **竞品商标**：对比图不出现竞品品牌名/商标，用通用示意或打码。
5. **标题过长**：主标题控制在可读范围，亚马逊首图文字需符合平台规则。
6. **首图加文案**：首图默认纯产品图，除非用户要求。
