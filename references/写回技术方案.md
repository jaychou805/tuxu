# 写回技术方案（.xls 保留图片）

## 问题

- `.xls` 是 OLE 复合文档（文件头 `D0 CF 11 E0`）。
- `xlrd` 只能读，不能写。
- `xlutils.copy` 复制工作簿会**丢失嵌入的图片对象**（DISPIMG 参考截图，存在 OLE 图片流里），文件从 17MB 缩到 34KB。
- `openpyxl` 只支持 `.xlsx`，不支持 `.xls`。

## 正确方案：pywin32 + WPS COM

用 WPS 的 COM 接口直接改单元格，图片 100% 保留。

### 环境准备

```bash
# 用隔离 venv
python -m venv <venv>
<venv>/Scripts/pip install xlrd pywin32
```

### COM ProgID

- WPS 表格：`KET.Application`（已验证可用）
- WPS 新版也试 `ET.Application`（本案例报「无效的类字符串」，回退 KET）
- MS Excel：`Excel.Application`

### 关键踩坑

1. **文件被预览占用**：腾讯文档/IDE 预览进程会锁定 `.xls`，导致：
   - `Workbooks.Open` 返回 `None`（`AttributeError: 'NoneType' has no attribute 'Worksheets'`）
   - 直接 `shutil.copy2` 覆盖报 `PermissionError: Device or resource busy`
   - 用 `Dispatch`（复用实例）会连到被占用的实例，调用被拒 `被呼叫方拒绝接收呼叫`
   
   **解决**：
   - 用 `DispatchEx('KET.Application')` 强制开**新实例**。
   - 编辑**副本**（`shutil.copy2(src, tmp)`），再尝试覆盖原文件。
   - 覆盖失败则：请用户关闭预览，或用新文件名交付（如 `xxx_v2.xls`）。

2. **DisplayAlerts/Visible 设置可能报错**：用 try/except 包裹，不影响核心写入。

3. **定位 sheet**：遍历 `wb.Worksheets` 按 `s.Name` 匹配，不要用索引（sheet 顺序可能变）。

4. **单元格写入**：`ws.Cells(row1based, col1based).Value = text`。行号从 1 开始（Python 里 0-based 的 r 要写 `r+1`）。

## 复用脚本

完整可复用脚本见 `scripts/fill_xls.py`，用法：改 `SRC`、`SHEET_NAME`、`CELLS`（{行号: {列号: 文本}}）后运行。
